## Summary
Tính năng tạo QR code chia sẻ thiệp đẹp.

## Details
- Thêm giao diện/modal tạo mã QR code chứa link public của thiệp.
- Trang trí QR code cho đẹp (thêm viền, màu sắc, logo chữ hỷ hoặc tim ở giữa) để cô dâu chú rể có thể tải về in hoặc gửi bạn bè.

## Acceptance Criteria
- [ ] Nút "Chia sẻ" hoặc "Tạo QR" trên giao diện Editor hoặc TopBar.
- [ ] Modal hiện mã QR thiết kế đẹp mắt chứa link `/?view=invitation&uid=...`.
- [ ] Cho phép tải xuống ảnh QR code.
