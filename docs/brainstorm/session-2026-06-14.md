# Brainstorm Session: Thiệp Cưới Template Overhaul
Date: 2026-06-14

## Quyết Định
- **Loại bỏ toàn bộ template cũ** (modern, luxury, traditional, floral, romantic, minimalist, vintage, garden)
- **Thay bằng 4 template mới** dựa trên references trong `public/theme/`:
  1. **traditional** — Truyền thống (Heritage Red, Playfair Display)
  2. **romantic** — Lãng mạn (Soft Pink, Great Vibes script)
  3. **modern** — Hiện đại tối giản (Blue, Noto Serif + Inter)
  4. **royal** — Royal Elegance (Heritage editorial style)

## Thiết kế chung
- Mỗi template = 1 bộ CSS variables riêng (colors, fonts)
- Cùng 1 layout structure (hero → countdown → story → events → gallery → gift → RSVP → footer)
- Khác nhau: color palette, font family, hero style, card styles, divider styles

## Files cần thay đổi
1. `types.ts` — cập nhật templateId union type
2. `InvitationManager.tsx` — cập nhật TEMPLATES array
3. `InvitationPreview.tsx` — viết lại với multi-theme support
4. `store/useStore.ts` — cập nhật DEFAULT_INVITATION templateId
