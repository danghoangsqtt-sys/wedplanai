# Brainstorm Session: Password Protection + Cloud Auto-Save
Date: 2026-06-15

## Mục Tiêu
Đây là công cụ cá nhân (1 người dùng). Cần 2 tính năng:
1. **Màn hình mật khẩu** bảo vệ app trước khi vào
2. **Auto-save lên Supabase** để mọi dữ liệu không bao giờ mất

---

## Quyết Định

### [Feature 1] Password Gate
- Hiển thị màn hình nhập PIN mỗi lần mở app (mỗi lần refresh/load lại tab)
- Session unlock: dùng `sessionStorage` — khi đóng tab thì khoá lại
- PIN được so sánh với hash SHA-256 hardcode trong source (không lưu plain text)
- UI: màn hình đơn giản, đẹp, full-screen — nhập PIN 6 số → Enter → vào app
- Không cần "quên mật khẩu" (công cụ cá nhân, owner biết PIN)

### [Feature 2] Supabase Auto-Save
- **Fixed UID hardcode**: 1 UUID cố định trong source code (vd: trong `lib/constants.ts`)
  - Lý do: không có auth system, chỉ 1 người dùng → ID cố định là đủ
- **Re-enable `triggerCloudSync`** trong `store/useStore.ts:172`
  - Hiện tại: bị comment out `// Cloud sync disabled`
  - Cần: gọi `saveUserDataToCloud(uid, data)` sau mỗi mutation
- **Load on startup**: sau khi vượt qua password gate → load dữ liệu từ Supabase
- **Dữ liệu được sync** (đã có sẵn trong `cloudService.ts`):
  - `guests`, `budgetItems`, `procedures`
  - `fengShuiProfile`, `fengShuiResults`
  - `invitation` (thiệp cưới — quan trọng nhất)
  - `weddingDate`
- **Debounce**: chờ 2 giây sau thay đổi mới sync, tránh spam API

## Phân Tích Kỹ Thuật Hiện Tại

### Đã có sẵn (không cần viết lại):
- `services/cloudService.ts` — `saveUserDataToCloud()`, `loadUserDataFromCloud()` hoàn chỉnh
- `store/useStore.ts` — `triggerCloudSync` function đã tồn tại, chỉ cần uncomment + implement
- Supabase tables đã có: `user_data`, `profiles`, `public_invitations`

### Cần thêm mới:
| File | Thay đổi |
|---|---|
| `components/PasswordGate.tsx` | Component mới — màn hình PIN full-screen |
| `lib/constants.ts` | `OWNER_UID` (UUID cố định) + `PIN_HASH` (SHA-256 của PIN) |
| `App.tsx` | Wrap app trong `<PasswordGate>` check |
| `store/useStore.ts:172` | Implement `triggerCloudSync` — gọi `saveUserDataToCloud` |
| `store/useStore.ts` | Thêm `loadFromCloud()` action — gọi khi app khởi động |

### Luồng hoạt động sau khi hoàn thành:
```
Mở app
  → PasswordGate check sessionStorage['unlocked']
    → Chưa unlock: hiện PIN screen
      → Nhập đúng PIN → set sessionStorage['unlocked'] = true
        → loadFromCloud(OWNER_UID) → populate store
          → App hiện ra bình thường
    → Đã unlock: App hiện thẳng (đã load từ persist/localStorage)
  
Thay đổi dữ liệu (thêm khách/sửa thiệp/...)
  → triggerCloudSync debounce 2s
    → saveUserDataToCloud(OWNER_UID, currentState)
      → Supabase upsert → data được lưu cloud
```
